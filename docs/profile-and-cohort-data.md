# Profile and cohort data

Skolo Saka registration stays minimal: the only required identity field is a verified phone number.

Users can optionally maintain:
- first name
- surname
- email address

Each school membership can additionally record:
- year the user left the school
- grade the user left in

The combination of school, year and grade can later support cohort matching, classmate discovery, reunion drives and targeted school-year campaigns.
