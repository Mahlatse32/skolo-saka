# Sign-in completion checklist

- Fresh URL opens phone + PIN sign-in.
- Existing configured account signs in without SMS.
- New user chooses Register, enters phone only, verifies SMS OTP, creates PIN.
- Existing user can use the same SMS flow to reset a forgotten PIN.
- Sign out returns to phone + PIN sign-in.
- Profile can save optional name, surname and email.
- Adding a school captures year left and grade left.
